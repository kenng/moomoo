# Momo

Personal moomoo news, positions, and option-timing checks.

## Language

**Strategy check**:
One scored timing evaluation of an underlying for a single option strategy.
_Avoid_: Signal, rating, screen

**Condition**:
One row in a strategy check, judged pass, warn, or fail.
_Avoid_: Filter, rule, criterion

**Penalty**:
The weighted sum of condition verdicts (fail = 2, warn = 1, pass = 0).
_Avoid_: Score, points

**Conclusion**:
The rollup label of a strategy check: Ideal, Favorable, Wait-and-see, or Avoid.
_Avoid_: Verdict, signal, recommendation

**Bull put spread**:
A credit put vertical; the first registered option strategy for a strategy check.
_Avoid_: CSP, short put, put credit spread
